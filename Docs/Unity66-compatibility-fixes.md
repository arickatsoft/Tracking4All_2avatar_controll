# Unity 6000.6 compiler compatibility

2026-09-09: The project has been upgraded from Unity 6000.2.9f1 to the installed 6000.6.0f1. The supplied compile errors came from APIs removed in that newer Editor.

Fixed:
- UniVRM's muscle inspector now aliases TreeView<int>, TreeViewItem<int> and TreeViewState<int> under UNITY_6000_6_OR_NEWER. Its identifiers are muscle/bone indices, not Unity object IDs.
- MediaPipe GraphRunner uses EntityId as its registry key on Unity 6000.6, retaining the old path for earlier versions. TextureFrame's independent Guid-returning GetInstanceID methods remain unchanged.
- Two project diagnostics/provider-identification scripts use GetEntityId.
- The MCP package is now a persistent local copy under Packages/com.coplaydev.unity-mcp. Its JSON serialization and object lookup preserve full entity identifiers, and its console reflection supports the new field name. See the package's UNITY66-COMPATIBILITY.md.

Validation: compiled MCPForUnity.Runtime, MCPForUnity.Editor, Mediapipe.Unity.Sample, UniHumanoid.Editor, MediaPipe.Unity.Sample.Tests.EditMode, Assembly-CSharp and Assembly-CSharp-Editor using the installed Unity 6000.6 Roslyn compiler and Unity-generated response files. Outputs were redirected to /tmp/fitfight-unity66 to avoid replacing Unity's live assemblies. All seven assemblies passed. Existing warnings remain. This is actual C# compilation against Unity's assemblies, not merely syntax parsing; it does not establish Play Mode behavior or a successful mobile build.

Unity needs to refresh the local package and source changes. Return to the Editor and allow the import/compile cycle to finish; use Assets > Refresh if automatic refresh is disabled. The Editor-owned packages-lock.json should be regenerated by Unity rather than manually patched. Old Console entries can remain until cleared.

Direct window verification was unavailable because Computer Use permissions were pending. The posted errors are fixed in source and the affected assemblies compile independently; live Console clearing/domain reload has not been confirmed.

Original project source/manifest copies are saved in Docs/Unity66-compatibility-originals.zip. The upstream cached MCP package was not modified.
